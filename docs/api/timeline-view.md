# TimelineView

The active file's undo history as a timeline, with its branches. Choosing a step goes back, or forward, to it.

`import { TimelineView } from "glass-ux-ide/workbench"`

[Live examples](https://dastari.github.io/glass-ux-ide/components/timeline-view)
