# SearchView

Search across files: `backend.search` when the application has one, otherwise in the page.

`import { SearchView } from "glass-ux-ide/workbench"`

[Live examples](https://dastari.github.io/glass-ux-ide/components/search-view)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| defaultQuery | `string \| undefined` | See type | no | "" | What to search for at first. |
