# WorkbenchStatusBar

The bar under a workbench: problems, the caret, the file's size and any shortcut in progress.

`import { WorkbenchStatusBar } from "glass-ux-ide/workbench"`

[Live examples](https://dastari.github.io/glass-ux-ide/components/workbench-status-bar)

## Props

| Prop | Type | Valid options | Required | Default | Description |
| --- | --- | --- | --- | --- | --- |
| className | `string \| undefined` | See type | no | — | Classes applied to the outer element for layout. Use the component props and theme tokens for its appearance. |
